3. O que é o PCShare

O PCShare é um software de acesso remoto para Windows. São dois programas:

  • PCShare Agente (gratuito): instalado por quem permite que sua própria máquina seja acessada.

A conexão entre as duas máquinas é cifrada de ponta a ponta.
